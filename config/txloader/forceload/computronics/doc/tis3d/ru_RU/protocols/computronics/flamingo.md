# Розовый фламинго

![Да, он существует.](block:Flamingo:flamingo.flamingo)

Недокументированная способность модуля последовательного порта толкать предметы позволяет заставить фламинго покачиваться. При записи любого значения в последовательный порт модуль заставляет фламинго качнуться, словно его толкнул человек.
