# Модуль считывания кассет

![Никаких проблем с хранением.](item:computronics:computronics.modules.tis3d@1)

Модуль считывания кассет может взаимодействовать с соседним стримером, записывая данные на вставленную в него ленточную кассету и считывая их с неё. Он также позволяет воспроизводить музыку с кассеты, если данные закодированы в формате [DFPWM](http://wiki.vex.tty.sh/dfpwm).

Длительность кассет составляет от 2 до 128 минут, и на них можно хранить любые данные (объём в мегабайтах примерно равен длительности записываемого звука DFPWM в минутах, делённой на 4).

Модуль принимает команды следующим образом: он непрерывно считывает значения со всех четырёх портов. Получив значение, он проверяет, является ли оно номером допустимой команды. Если да, модуль переходит к следующему этапу этой команды: ожидает дополнительные данные (параметр) на всех портах либо начинает записывать возвращаемые данные во все четыре порта. Выполнив команду, он снова начинает считывание со всех портов в ожидании следующей команды.

Доступны следующие команды:

* `0`: isEnd — возвращает 1, если стример пуст или вставленная кассета закончилась; иначе 0.
* `1`: isReady — возвращает 1, если кассета вставлена; иначе 0.
* `2`: getState — возвращает текущее состояние стримера в виде числа: `0` — остановлен, `1` — воспроизводит запись, `2` — перематывает назад, `3` — перематывает вперёд.
* `3`: getSize — возвращает размер кассеты в байтах по модулю 1024.
* `4`: getSize в кибибайтах — возвращает размер кассеты в кибибайтах, округлённый вниз до целого числа.
* `5`: setSpeed — устанавливает скорость воспроизведения стримера в процентах на следующее считанное модулем значение. Допустимы значения от 25 до 200.
* `6`: setVolume — устанавливает громкость стримера в процентах на следующее считанное модулем значение. Допустимы значения от 0 до 100.
* `7`: seek — перемещает ленту на следующее считанное модулем значение в байтах. Отрицательные значения перемещают ленту назад (то есть перематывают её).
* `8`: seek в кибибайтах — перемещает ленту на следующее считанное модулем значение в кибибайтах. Отрицательные значения перемещают ленту назад (то есть перематывают её).
* `9`: read — считывает один байт с кассеты и возвращает его.
* `10`: read нескольких байтов — считывает с кассеты количество байтов, равное следующему полученному модулем значению, и возвращает их по одному. Пример: параметр `4` заставит модуль выполнить запись во все свои порты 4 раза, каждый раз возвращая один считанный байт.
* `11`: write — записывает на кассету следующее полученное модулем значение.
* `12`: write нескольких байтов — следующее считанное модулем значение задаёт количество байтов для записи на кассету. Каждое последующее считанное значение записывается на кассету, пока не будет записано заданное количество байтов.
* `13`: switchState — устанавливает состояние стримера на следующее полученное модулем значение. Допустимые числа указаны для команды 2 (getState).
