# Разноцветный модуль

![Слишком красиво.](item:computronics:computronics.modules.tis3d@0)

Работающий разноцветный модуль непрерывно считывает значения со всех четырёх портов и меняет свой цвет на полученное значение.

Цвет задаётся 15-битным двоичным числом. Последние 5 разрядов определяют оттенки синего, средние 5 — зелёного, а первые 5 — красного. Например, двоичное число `000000000011111` (после преобразования в десятичное) задаёт синий цвет.
