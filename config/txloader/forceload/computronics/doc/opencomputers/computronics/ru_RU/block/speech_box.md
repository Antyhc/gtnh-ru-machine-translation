# Речевой ящик

![Понадобилось всего два года.](block:computronics:computronics.speechBox)

Речевой ящик умеет говорить! Он использует систему синтеза речи [MaryTTS](http://mary.dfki.de/), чтобы озвучивать любые сообщения. Передайте ему предложение или фразу, и после некоторой интенсивной обработки он её произнесёт. Правильная пунктуация обычно улучшает качество произношения.

Из-за большого размера системы ящик по умолчанию ничего не делает: для работы MaryTTS нужно отдельно установить в каталог игрового экземпляра. Подробная инструкция по установке находится [на вики](http://wiki.vex.tty.sh/wiki:computronics:mary).

Если к ящику подключён [звуковой кабель](audio_cable.md), во время работы он передаёт созданный звуковой сигнал по кабелю, а не воспроизводит его самостоятельно.
