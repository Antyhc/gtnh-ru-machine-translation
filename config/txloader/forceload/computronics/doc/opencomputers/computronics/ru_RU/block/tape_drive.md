# Стример

![Клейкую ленту не вставлять.](block:computronics:computronics.tapeReader)

Стример — блок для записи и воспроизведения звуковых данных. В него вставляются [ленточные кассеты](../item/tape.md) длительностью от 2 до 128 минут. Стример не ограничен звуком: на [кассету](../item/tape.md) можно записывать и другие виды данных.

Звук записывается в формате DFPWM, позволяющем получать файлы небольшого размера. Преобразование MP3 и других распространённых форматов непросто, но WAV можно перевести в DFPWM программой [LionRay](http://wiki.vex.tty.sh/wiki:computronics:tape#lionray). Полученный звуковой файл затем записывается на кассету побайтно. Дополнительные сведения о DFPWM есть [на вики](http://wiki.vex.tty.sh/dfpwm).

У стримера есть функция `seek()`, позволяющая быстро перейти к заданной позиции на [ленточной кассете](../item/tape.md). Отрицательное значение, переданное в `seek()`, перематывает [кассету](../item/tape.md) назад.

Можно создать дискету `tape` с одноимённой программой для удобного чтения, записи и воспроизведения кассет.

Если к стримеру подключён [звуковой кабель](audio_cable.md), при воспроизведении он передаёт созданный звуковой сигнал по кабелю, а не воспроизводит его самостоятельно.
