# Шумящая карта

![Буп. Бип. Бз-з-т.](item:computronics:computronics.ocParts@8)

Подобно [гудящей карте](beep_card.md), шумящая карта предоставляет функцию `play()`. Кроме того, для каждого из восьми независимых каналов можно выбрать форму звуковой волны: прямоугольную, синусоидальную, треугольную или пилообразную.

Карта также имеет небольшой внутренний буфер. Для каждого канала в нём можно задать до восьми пар «частота — длительность» с необязательной начальной задержкой. Вызов `process()` обрабатывает весь буфер целиком.

Пример кода:
`  local card = require("component").noise`
`  card.setMode(1, card.modes.sawtooth)`
`  card.play({{440, 4}, {880, 2}})`
Этот код воспроизводит пилообразную волну частотой 440 Гц в течение 4 секунд и прямоугольную волну частотой 880 Гц в течение 2 секунд.

Пример кода с буфером:
`  local card = component.noise`
`  card.setMode(1, card.modes.sawtooth)`
`  card.add(1, 440, 4)`
`  card.add(2, 880, 1, 2)`
`  card.add(2, 220, 1)`
`  card.process()`
