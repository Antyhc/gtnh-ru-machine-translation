# Радар

![Радиообнаружение и определение расстояния](block:computronics:computronics.radar)

Радар работает подобно датчику движения Open Computers и обнаруживает сущности: игроков, мобов и выброшенные предметы. Встроенные функции API возвращают таблицу имён сущностей в указанном радиусе и расстояний до них.

Для сканирования больших областей радару требуется определённое количество энергии (в Open Computers) либо возникает задержка между сканированиями (в ComputerCraft).
