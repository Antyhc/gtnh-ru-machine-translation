# Блок шифрования

![Загадочно.](block:computronics:computronics.cipher)

Блок шифрования служит для шифрования и расшифровки сообщений. В него можно поместить предметы, чтобы создать ключ шифрования на основе данных Itemstack. Затем сообщения можно расшифровать блоком с точно таким же ключом. Например, зашифрованные сообщения можно отправлять другим компьютерам в сети; для их расшифровки принимающему компьютеру понадобится блок шифрования с тем же сочетанием предметов. Через API компонента блок можно заблокировать, закрыв доступ к его интерфейсу и скрыв ключ шифрования.
