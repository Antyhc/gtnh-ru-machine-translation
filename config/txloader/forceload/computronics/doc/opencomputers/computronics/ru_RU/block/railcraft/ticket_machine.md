# Автомат для печати билетов

![Бз-з-з. Бз-з-з-з. Бз-з-з-з.](block:computronics:computronics.ticketMachine)

Автомат печатает билеты по шаблону золотых билетов. Золотые билеты настраиваются через API компонента `ticket_machine` или через интерфейс в режиме обслуживания: нажмите ПКМ пустой рукой по автомату с зажатой клавишей приседания. После настройки билеты можно печатать в интерфейсе, выбрав золотой билет и нажав кнопку печати, либо через API компонента, указав нужный слот золотого билета. Печать требует энергии и обычной бумаги Minecraft. Бумагу можно поместить в соответствующий слот в режиме обслуживания или средствами автоматизации.

При необходимости через API компонента можно запретить ручную печать в интерфейсе; тогда печатать билеты смогут только функции API. Доступ к режиму обслуживания также можно ограничить владельцем устройства и операторами сервера.
