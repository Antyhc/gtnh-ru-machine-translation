# Железный нотный блок

![Лучше обычного нотного блока.](block:computronics:computronics.ironNoteBlock)

Железный нотный блок воспроизводит различные ноты разными инструментами. Набор инструментов, например фортепиано или бас-барабан, соответствует нотному блоку Minecraft. Для каждого инструмента доступно 24 ноты; также можно указать необязательный параметр громкости от 0 до 1.
