# Карта эффектов частиц

![Все хотят красивые частицы.](item:computronics:computronics.ocParts@3)

Карта эффектов частиц позволяет компьютерам, роботам и дронам со слотом улучшений уровня 2 или выше создавать частицы в заданной точке относительно устройства. Имя частицы, передаваемое функции API компонента, должно быть допустимым именем частицы Minecraft.
