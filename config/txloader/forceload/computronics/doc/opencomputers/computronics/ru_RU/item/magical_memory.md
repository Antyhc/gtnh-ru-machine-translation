# Магическая память

![Мнемонические шедевры](item:computronics:computronics.ocSpecialParts@0)

Это магическое устройство — разновидность [памяти](/%LANGUAGE%/item/ram1.md), которая, похоже, хранит данные в байтах, собранных из окружающей среды, космического излучения, Scumm™ и ошибок на единицу. Это делает её практически безгранично мощной. К счастью, артефакт нельзя ни найти, ни изготовить: из-за сокращения бюджета его воздействие на вселенную ещё не проверяли, и полное разрушение не исключено. Впрочем, специалисты склонны считать, что вместо поглощения вселенной он просто предоставит компьютеру очень много доступной памяти.
