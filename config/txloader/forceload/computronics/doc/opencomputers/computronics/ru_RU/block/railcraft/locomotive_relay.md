# Цифровое локомотивное реле

![Добро пожаловать в будущее.](block:computronics:computronics.locomotiveRelay)

Цифровое локомотивное реле позволяет компьютеру взаимодействовать с электрическим локомотивом Railcraft. Для сопряжения нужен [цифровой датчик реле](../../item/railcraft/relay_sensor.md): нажмите им ПКМ с зажатой клавишей приседания, чтобы привязать [датчик](../../item/railcraft/relay_sensor.md) к реле, затем нажмите ЛКМ с зажатой клавишей приседания по электровозу, чтобы установить [датчик](../../item/railcraft/relay_sensor.md). После этого электровозом можно управлять через API компонента `locomotive_relay`.
