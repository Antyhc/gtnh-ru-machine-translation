# Цветная лампа

![Какая красота.](block:computronics:computronics.colorfulLamp)

Цветная лампа — особый светящийся блок, поддерживающий до 32768 сочетаний цветов. Цвет задаётся 15-битным двоичным числом. Последние 5 цифр определяют оттенок синего, средние 5 — зелёного, а первые 5 — красного. Например, двоичная запись `000000000011111`, переведённая в десятичное число, задаёт синий цвет. Лампу можно использовать как индикатор состояния: разные цвета будут соответствовать различным состояниям программы на компьютере.
