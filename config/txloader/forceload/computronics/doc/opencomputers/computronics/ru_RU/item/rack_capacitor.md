# Конденсатор стойки

![У меня есть энергия!](item:computronics:computronics.ocParts@12)

Конденсатор стойки — это [конденсатор](/%LANGUAGE%/block/capacitor.md), устанавливаемый в [серверную стойку](/%LANGUAGE%/block/rack.md). Он обладает преимуществами обычного [конденсатора](/%LANGUAGE%/block/capacitor.md), но не получает бонуса за соседство.

Этот конденсатор предоставляет компонент `rack_capacitor`, через который можно в любой момент узнать запас энергии. Это полезно для проверки сети на проблемы с питанием.
