# Звуковая карта

Звуковая карта — сложное устройство для синтеза звука с высокой точностью. Подобно [шумящей карте](noise_card.md), она позволяет создавать звуковые волны различной формы.

Звуковая карта предоставляет восемь каналов, каждый из которых может самостоятельно генерировать волну. Однако любой канал можно назначить для модуляции частоты и амплитуды другого. В этом случае он сам не издаёт звука, а изменяет волну несущего канала.

Звуковая карта работает на основе инструкций. Различные функции карты позволяют добавлять инструкции во внутреннюю очередь. Инструкция может изменить форму и частоту волны канала, назначить один канал для модуляции другого, задать для канала [ADSR](https://en.wikipedia.org/wiki/Synthesizer#Attack_Decay_Sustain_Release_.28ADSR.29_envelope) или просто изменить его громкость.
По умолчанию все каналы закрыты; их нужно открывать соответствующими инструкциями. Закрытые каналы обычно не издают звука (если задана огибающая ADSR, закрытие запускает фазу затухания).

Чтобы звук воспроизводился в течение заданного времени, можно использовать инструкцию задержки: тогда все настройки, изменённые предыдущими инструкциями, будут действовать во время неё. Длительность задаётся в миллисекундах, что обеспечивает высокую точность синтеза. Добавив в очередь все необходимые инструкции, вызовите `process()`, чтобы обработать их и воспроизвести звук.

Пример:

`  local sound = require("component").sound`

`  sound.setWave(1, sound.modes.sine)`
`  sound.setFrequency(1, 440)`
`  sound.open(1)`
`  sound.delay(1000)`
`  sound.close(1)`
`  sound.process()`

Этот пример открывает первый канал для воспроизведения звука во время задержек и задаёт ему синусоидальную волну частотой 440 Гц (нота ля первой октавы, A4), а затем снова закрывает канал.

`  sound.setWave(2, sound.modes.noise)`
`  sound.setFrequency(2, 440)`
`  sound.setVolume(2, 0.6)`
`  sound.setADSR(2, 0, 250, 0, 0)`
`  sound.open(2)`
`  sound.delay(1500)`
`  sound.close(2)`
`  sound.process()`

Этот пример открывает второй канал и задаёт ему белый шум частотой 440 Гц с пониженной громкостью. Огибающая ADSR снижает громкость от заданного значения до 0 за 250 мс.
