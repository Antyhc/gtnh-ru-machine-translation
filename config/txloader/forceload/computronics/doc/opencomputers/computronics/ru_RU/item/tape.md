# Ленточная кассета

![Может содержать музыку.](item:computronics:computronics.tape@0)

Ленточные кассеты используются для записи и воспроизведения звука с помощью [стримера](../block/tape_drive.md). Их длительность составляет от 2 до 128 минут; на них также можно хранить другие данные (объём в мегабайтах примерно равен длительности кассеты в минутах, делённой на 4). Звук записывается в формате DFPWM, описанном на странице [стримера](../block/tape_drive.md).
