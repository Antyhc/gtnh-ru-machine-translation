# Гудящая карта

![Бип. Бип. Бип.](item:computronics:computronics.ocParts@5)

Эта карта предоставляет функцию `beep()`, которая принимает таблицу пар «частота — длительность», до восьми записей одновременно. Карта воспроизводит сигнал каждой частоты в течение указанного времени. Когда воспроизведение одной частоты завершено, карте можно передать новую пару. Одновременно воспроизводить более восьми частот нельзя.

Пример кода:
`  local card = component.beep`
`  card.beep({[440]=4, [880]=2})`
