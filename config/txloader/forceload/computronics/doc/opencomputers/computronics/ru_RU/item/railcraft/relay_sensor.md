# Цифровой датчик реле

![Одноразовый.](item:computronics:computronics.relaySensor)

Цифровой датчик реле используется для сопряжения [локомотивного реле](../../block/railcraft/locomotive_relay.md) с электрическим локомотивом Railcraft. Для сопряжения сначала щёлкните датчиком правой кнопкой мыши по [локомотивному реле](../../block/railcraft/locomotive_relay.md), удерживая клавишу приседания, а затем, не отпуская её, щёлкните левой кнопкой мыши по электрическому локомотиву, чтобы прикрепить датчик.
