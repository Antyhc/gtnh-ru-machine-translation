# Продвинутый блок шифрования

![Почти безопасно.](block:computronics:computronics.cipher_advanced)

Продвинутый блок шифрования использует RSA и создаёт пару из открытого и закрытого ключей. Пару ключей можно получить из двух простых чисел или сгенерировать случайным образом. После завершения генерации, которая занимает несколько секунд, возвращаются оба ключа.
Открытый ключ служит для шифрования сообщений, а закрытый — для расшифровки. Расшифровать сообщения могут только устройства, у которых есть закрытый ключ.
