# Световая доска

![И сказал Notch: да будет свет.](item:computronics:computronics.ocParts@10)

Эта плата устанавливается в серверные стойки. Она содержит четыре световых индикатора, которыми подключённые компьютеры управляют через компонент `light_board`.

Расположение индикаторов можно изменить, применив к плате любой [гаечный ключ](/%LANGUAGE%/item/wrench.md). Учтите, что настройки цветов при этом сбрасываются.
