# Чатбокс

![Поговори со мной!](block:computronics:computronics.chatBox)

Чатбокс позволяет компьютеру читать и отправлять сообщения в чате Minecraft. Для чтения и отправки сообщений можно задать радиус действия (по умолчанию: 40 блоков). Программы на компьютере могут реагировать на сообщения, читая их из события `chat_message`.

При получении сообщения чатбокс выдаёт импульс красного камня длительностью 4 такта, что позволяет использовать его с различными схемами управления.
